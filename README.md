# AP Computer Science Principles: Pong Game

A 2D Pong arcade application as a task project for AP Computer Science Principles.
This project implements fundamental CS concepts including object-oriented software design, 2D vector kinematics, and collision detection algorithms.

## Key Features

- **2D Physics:** Axis-aligned bounding box (AABB) collision checks for paddle-ball bounces and boundary detection.
- **Game State Machine:** Smooth transitions between start screens, active gameplay loops, point tracking, and game-over states.
- **Custom Player Controls:** Event-driven input processing handling simultaneous key events for paddle movement.
- **Score System:** Dynamic score calculations and win-condition checks.
